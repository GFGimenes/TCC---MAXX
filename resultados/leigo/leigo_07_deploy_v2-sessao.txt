● Dá pra fazer de dois jeitos, conforme o que você quer.

  1. Abrir no seu celular (teste rápido, sem custo)

  Funciona se o celular estiver no mesmo Wi-Fi que o computador:

  1. No computador, rode npm start como sempre.
  2. No navegador do celular, abra http://192.168.x.x:3000
  3. Se não carregar, o Windows provavelmente bloqueou. Quando aparecer o aviso
     do Firewall, clique em Permitir (marque "Redes privadas").

  Esse link não serve pros seus amigos. Ele só funciona dentro da sua casa.

  2. Mandar um link pros amigos

  O Maxx precisa estar rodando em algum lugar acessível pela internet. Há duas
  opções:

  ┌───────────┬────────────────────────────────────┬───────────────────────┐
  │           │      Túnel a partir do seu PC      │  Hospedagem na nuvem  │
  ├───────────┼────────────────────────────────────┼───────────────────────┤
  │           │ Seu computador continua rodando o  │ O app roda num        │
  │ Como      │ app e um programa gratuito         │ servidor (ex.:        │
  │ funciona  │ (Cloudflare Tunnel) cria um link   │ Railway) 24h por dia  │
  │           │ público                            │                       │
  ├───────────┼────────────────────────────────────┼───────────────────────┤
  │ Custo     │ Grátis, sem cadastro               │ Cerca de US$ 5/mês    │
  ├───────────┼────────────────────────────────────┼───────────────────────┤
  │ Ponto     │ Só funciona com o PC ligado e o    │ Dá mais trabalho na   │
  │ fraco     │ npm start aberto, e o link muda    │ primeira configuração │
  │           │ toda vez que você reinicia         │                       │
  ├───────────┼────────────────────────────────────┼───────────────────────┤
  │ Bom para  │ Testar com a turma num fim de      │ Deixar no ar de       │
  │           │ semana ou no dia da apresentação   │ verdade               │
  └───────────┴────────────────────────────────────┴───────────────────────┘

  Um aviso: hospedagens gratuitas como o Render apagam os dados quando
  reiniciam. O Maxx guarda o banco e as fotos na pasta dados/, então ali os
  posts e as contas sumiriam. Por isso indiquei uma opção paga com disco
  permanente.

  Antes de publicar, três coisas importantes

  1. Troque a senha do admin. A senha padrão unimax-admin está escrita no
     README, que é público no GitHub. Qualquer pessoa que tiver o link poderia
     entrar como faculdade.
  2. Seus amigos não vão conseguir criar conta. O cadastro só aceita e-mails
     @unimax.edu.br. Para eles entrarem, você pode:
     - acrescentar o domínio do e-mail da faculdade de vocês em src/config.js,
       ou
     - usar o código da banca (CODIGO_BANCA). Nesse caso todos entram nas mesmas
       contas de teste, sem conta própria.
  3. Ajuste no código para funcionar online. Por enquanto o app não reconhece o
     endereço de cada visitante quando roda atrás de um túnel ou servidor. Aí
     todo mundo conta como uma pessoa só no limite de tentativas do código da
     banca: 10 erros somados bloqueiam todos por 15 minutos. Resolve com uma
     linha (trust proxy).

  Quer que eu prepare isso? Posso fazer o ajuste do item 3, deixar a troca de
  domínio e a senha do admin fáceis de configurar e então montar o túnel
  gratuito ou a hospedagem passo a passo. Qual das duas opções você prefere?

❯ Mas no gratis meu computador vai precisar ficar ligado o tempo todo chat ?    
  Queria que pudesse usar mesmo com ele desligado                               

● Sim. No túnel gratuito o Maxx roda no seu computador, então ele precisa ficar
  ligado com o npm start aberto. Desligou, o link para de funcionar.

  Para funcionar com o PC desligado, o app tem que rodar num servidor na nuvem.
  O problema é que o Maxx guarda o banco e as fotos na pasta dados/. Por isso
  precisa de um servidor que não apague os arquivos quando reinicia. As
  hospedagens gratuitas simples (Render, Koyeb) apagam, e as contas e posts dos
  seus amigos sumiriam.

  Estas são as opções reais:

  Opção: Railway
  Custo: ~US$ 5/mês (dá pra testar com crédito grátis no começo)
  Dificuldade: Fácil: conecta no seu GitHub e publica
  Observação: Minha recomendação: é o mais simples para quem não é da área
  ────────────────────────────────────────
  Opção: Oracle Cloud "Always Free"
  Custo: Grátis de verdade
  Dificuldade: Mais difícil: é um computador vazio na nuvem que você configura
  Observação: Pede cartão no cadastro (não cobra). Eu te guio comando por
  comando
  ────────────────────────────────────────
  Opção: Mudar o Maxx para um banco online gratuito
  Custo: Grátis
  Dificuldade: Eu faço, mas é uma mudança grande no código
  Observação: Arrisca quebrar coisas que já funcionam no TCC; eu não recomendo
  agora

  Com Railway ou Oracle, o link fica fixo e no ar 24h por dia, com o seu PC
  desligado.

  Qual você prefere? Enquanto isso, já posso fazer os ajustes que valem para
  qualquer uma delas: corrigir o limite de tentativas quando o app roda online,
  trocar a senha do admin e liberar o e-mail da faculdade de vocês. Para isso,
  me diga qual é o domínio do e-mail de vocês (por exemplo,
  @aluno.suafaculdade.edu.br).
